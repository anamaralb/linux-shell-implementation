# Linux Shell Implementation

This project consists of the implementation of a Unix-like shell in C, developed as part of an Operating Systems course.

## Features

- Command execution
- Process management
- Pipes and redirection
- Background processes
- Signal handling

## Technologies

- C
- Linux / POSIX
- GCC
- Makefile

## Notes

This project was developed during my Robotics Engineering degree and is shared for portfolio purposes.
